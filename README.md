# The Meeting That Should Have Been One Line

An entry for the make.fun contest "The Meeting That Should Have Been One Line": a single sentence that could have replaced an entire pointless meeting — the decision was already in the original email, and the other fifty-nine minutes were just twelve people reading it out loud together.

## Run

```bash
python3 main.py
```

This writes the one-line entry to `/output/entry.txt` (creating the directory if needed).
